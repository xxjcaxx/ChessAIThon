# chessaithonapp

This is the Vite-based frontend demo for ChessAIThon.

Overview

- Built with Vite.
- Uses: chess.js, chessmarro-board, rxjs.

Local development

```bash
cd appchesintion/chessaithonapp
npm install
npm run dev
```

Build and preview

```bash
npm run build
npm run preview
```

Key files

- `index.html` — app entry.
- `src/` — application source code (main.js, router.js, components, styles).
- `public/` — static assets (e.g., `chess_endgames.csv`).

Notes

- Uses Vite dev server on default port (check console output when running `npm run dev`).
