# Welcome to ChessAIthon

This documentation covers the ChessAIthon project: a collection of chess AI experiments, datasets, and models developed for learning, research, and competitions.

Here you'll find guides for:

- Getting started with the code and datasets
- Understanding the Chessmarro model and other model artifacts
- Running training and inference locally
- Contributing and reproducing experiments

### Quick start — view the docs locally

1. Install dependencies at the documentation root:

```bash
npm install
# or
yarn
```

2. Start the local dev server:

```bash
npm run start
# or
yarn start
```

3. Open http://localhost:3000 to view the documentation.

Notes:
- The dataset `Practical chess endgames (for training) - General.csv` and `chess_endgames.csv` are available in the documentation `public/` folder for quick reference.
- Use the "Edit this page" links on docs pages to propose changes via GitHub.


If you prefer, jump to other docs pages in the sidebar to explore architecture diagrams, training notes, and the model documentation.
