# documentacion

Project documentation and the Docusaurus-powered docs site are in `documentacion/chessAIthon-documentation`.

Quick start (documentation site)

```bash
cd documentacion/chessAIthon-documentation
npm install
npm run start
```

Build

```bash
npm run build
```

Edit docs under `documentacion/chessAIthon-documentation/docs` and submit PRs for changes.
